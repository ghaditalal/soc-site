## About

This website introduces the concept of a Security Operations Center: what it is, what it does, who works in it, and how it responds to cyber incidents. The content is written in Arabic with a right-to-left (RTL) layout.

## Sections

- **What is a SOC?** Definition and its three pillars: people, processes, and technology
- **Core tasks:** monitoring, threat detection, incident response, threat hunting, threat intelligence, and vulnerability management
- **SOC team:** Tier 1, Tier 2, Tier 3 analysts and leadership, with the escalation path
- **Tools:** SIEM, SOAR, EDR, IDS/IPS, TIP, and firewalls
- **Incident response lifecycle:** the four phases of NIST SP 800-61, plus key metrics (MTTD, MTTR, false-positive rate)
- **SOC types:** in-house, managed (MSSP), hybrid, and virtual
- **FAQ** and an **interactive quiz**

## Features

- Simulated live SIEM alert feed
- Clickable tabs and flip cards
- Interactive 5-question quiz with scoring
- Fully responsive (works on mobile and desktop)
- No frameworks or libraries, just plain HTML, CSS, and JavaScript
